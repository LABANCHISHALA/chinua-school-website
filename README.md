# Chinua Primary & Secondary School Website

Static website (HTML, CSS, JS) ready for GitHub Pages.

## Publish
1. Create a GitHub repository and upload all files in this folder (keep the folder structure).
2. Go to **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repository>/`.

## Add your logo
Save your school logo as `assets/logo.png`.

## Add materials
Put files in `downloads/` and link them from `learners.html`.

## Note on privacy
GitHub Pages is public. Do not publish individual learner results or personal data here.
